# Тихий час

Готовая русскоязычная point-and-click игра с четырьмя головоломками.

Скачайте `quiet-hour.zip`, распакуйте архив и откройте `quiet-hour.html` в Chrome, Edge или Firefox на компьютере. Установка и интернет для игры не нужны.

Рисунки, звук и шрифты включены в HTML. Лицензии шрифтов сохранены внутри HTML в шаблоне `font-licenses`.

Это ветка с готовой сборкой; основная ветка проекта не изменена.
