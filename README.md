# Реактив — виртуальная химическая лаборатория

Приложение на **ASP.NET Core / .NET 10** с русским интерфейсом. Выбирайте два вещества, наблюдайте уравнение реакции и используйте полученные соединения в следующих экспериментах. Внешние библиотеки, база данных, ключи API и подключение к интернету для работы приложения не нужны.

В первом столбце — **все 118 элементов таблицы Менделеева**, во втором — продукты ваших реакций. В каталоге **2 380 веществ и 7 888 вариантов реакций**: 118 простых веществ и **2 262 соединения**. Все соединения достижимы из исходных элементов в рамках модели. Для пар вне справочника приложение сообщает об отсутствии предусмотренной реакции.

Это расширенный учебный симулятор, **не база всех известных человечеству соединений**. Большая часть новых записей строится по моделям химических классов; запись в каталоге не подтверждает экспериментальное получение или устойчивость конкретного вещества. В интерфейсе они помечены **«Модель класса»**, отдельно от **«Справочной реакции»**. Уравнения автоматически балансируются, однако баланс атомов не доказывает термодинамическую, кинетическую или экспериментальную осуществимость реакции.

## Что входит в большой каталог

- Оксиды и гидроксиды металлов; галогениды, сульфаты, нитраты, нитриты, карбонаты, сульфиты, фосфаты, кислые соли, сульфиды и соли аммония.
- Первичные спирты, альдегиды, карбоновые кислоты, алканы, алкены и галогеналканы с линейными цепями **C1–C30**, где класс допускает такое число атомов углерода.
- **900 сложных эфиров**: сочетания 30 кислот и 30 спиртов, гидролиз и омыление щелочами лития, натрия и калия.
- Ароматические вещества и отдельные цепочки: бензол, толуол, фенол, нитробензол, анилин, бензойная кислота, ацетон, изопропанол, этиленгликоль, глицерин, глюкоза и мальтоза.
- Несколько направлений для одной пары реагентов: выбирайте условия перед смешиванием. Например, `CO2 + H2O` может означать растворение CO2 с образованием угольной кислоты или суммарную схему фотосинтеза в живых клетках.

Схемы классов предполагают указанные среду, катализатор, температуру, соотношение реагентов и выбор продукта. Для длинных цепей, амфотерных соединений, гидролизующихся солей и органических изомеров реальная химия сложнее модели. Нестабильные сочетания вроде `FeI3`, `CuI2`, обычного `Al2(CO3)3` исключены из генерации; это не заменяет проверку остальных веществ по экспериментальным источникам. Источники и границы модели описаны в [CHEMISTRY.md](CHEMISTRY.md).

## Запуск в VS Code

1. Установите **.NET 10 SDK**: https://dotnet.microsoft.com/download/dotnet/10.0. Нужен именно SDK, а не только Runtime.
2. Откройте папку проекта в VS Code: в ней должен находиться `Grenade.csproj`.
3. Откройте встроенный терминал и выполните:

   ```sh
   dotnet run
   ```

4. Откройте **http://localhost:5186** в браузере. Если браузер не открылся автоматически, скопируйте адрес из терминала.

Для остановки нажмите `Ctrl+C`. Windows, Linux и macOS поддерживаются. Для отладки через `F5` установите расширение Microsoft **C#** (`ms-dotnettools.csharp`); настройки сборки и запуска уже включены в `.vscode`.

Если порт занят, используйте другой:

```sh
dotnet run --no-launch-profile --urls http://localhost:5187
```

## Как пользоваться

- **Первый столбец — все элементы таблицы Менделеева:** 118 карточек от водорода до оганесона, упорядоченных по атомному номеру. На карточке есть символ, русское название и номер элемента. Для реакций используются формулы простых веществ: например, кислород — `O2`, водород — `H2`.
- **Второй столбец — продукты реакций:** изначально пустой. Здесь появляются все полученные вещества, включая несколько продуктов одной реакции. Вода, кислоты, щёлочи и соли также сначала создаются реакциями.
- Нажмите на две карточки **из любых столбцов, включая один и тот же**, затем нажмите **«Смешать вещества»**. Повторное нажатие снимает выбор. Для веществ с предусмотренной реакцией с самим собой (например, глюкозы) два нажатия выбирают две порции. Чтобы заменить выбранное вещество, сначала нажмите на его ячейку на столе.
- Если для пары есть несколько вариантов, выберите **«Условия и продукт»** перед смешиванием. По умолчанию сохранены прежние основные реакции; история запоминает точный вариант.
- Можно **перетащить одну карточку на другую** для немедленного смешивания или перетащить её в ячейку стола. На телефоне пользуйтесь нажатиями.
- Полученные вещества доступны для следующих реакций без ограничения количества: это учебная модель, расход веществ не моделируется.
- Поиск понимает русские названия, символы, формулы (`O2` и `O₂`) и точный атомный номер (`26` — железо). Рядом находится фильтр типов веществ, включая полуметаллы и благородные газы.
- В **большом справочнике** переключайтесь между **реакциями** и **соединениями**, ищите по названию, молекулярной или сокращённой формуле и семейству. Есть постраничная навигация; кнопка **«Как получить»** показывает реакции для выбранного соединения. Реактивы, которые ещё не открыты, нужно предварительно получить.
- Кнопка с часами открывает журнал последних 50 успешных реакций, включая выбранные условия.
- Открытия и история автоматически сохраняются в `localStorage` текущего браузера для адреса приложения. Их можно удалить кнопкой **«Сбросить прогресс»** с подтверждением. Если сохранение браузером запрещено, приложение продолжает работать в текущей вкладке.
- Прогресс версии с тремя столбцами сохраняется. Если в старой истории использовался готовый реагент, которого ещё нет в новой коллекции продуктов, сначала получите его: кнопка повтора станет доступна.

### Пример цепочки

1. **Железо + кислород → оксид железа(III)**: `4Fe + 3O2 → 2Fe2O3`.
2. Выберите **оксид железа(III)** из второго столбца и **железо** из первого: `Fe2O3 + Fe → 3FeO`.
3. Получите **соляную кислоту** из водорода и хлора: `H2 + Cl2 → 2HCl`.
4. Смешайте **оксид железа(II)** и **соляную кислоту** из второго столбца: `FeO + 2HCl → FeCl2 + H2O`.

Пример двух других продуктов: сначала получите `CaO` из кальция и кислорода, затем `SiO2` из кремния и кислорода. Соедините обе карточки во втором столбце: `CaO + SiO2 → CaSiO3`.

Серную кислоту можно получить по цепочке: `S + O2 → SO2`, затем `2SO2 + O2 ⇌ 2SO3`, затем `SO3 + H2O → H2SO4`. Воду предварительно получите из водорода и кислорода.

Органическая ветка начинается с `CO2 + C → 2CO`, затем `CO + 2H2 → CH3OH`. Метанол можно окислить до формальдегида, получить муравьиную кислоту и её эфиры либо карбонилировать до уксусной кислоты. Выбранная модель карбонилирования и гидрирования позволяет строить цепочки до C30; она не утверждает одинаковую селективность и доступность катализаторов для всех гомологов.

Модель использует конечный справочник, а не пытается предсказать произвольную химическую реакцию. Для отсутствующей пары она прямо сообщает об этом. Условия указаны для каждого уравнения: например, продукт окисления железа зависит от температуры и доступности кислорода. Приложение не моделирует количества, скорость, равновесие и все возможные побочные продукты. В случае хлороводорода предполагается его последующее растворение в воде.

## Проверки

```sh
dotnet build --configuration Release
dotnet run --project tests/Grenade.Checks.csproj --configuration Release
```

Проверки запускаются без стороннего тестового фреймворка и завершаются ненулевым кодом при ошибке. Они проверяют полноту списка из 118 элементов, отсутствие соединений в первом столбце, 900 эфиров, сохранение разных изомеров, исключения генератора, выбор вариантов, независимость от порядка реагентов, **баланс атомов каждого уравнения**, соответствие уравнений каталогу и достижимость всех соединений в модели. Эти программные проверки не являются экспериментальной верификацией химии.

## Структура

```text
Program.cs                   HTTP-сервер и API
Domain/ChemistryCatalog.cs    Вещества, реакции, условия и пояснения
Domain/ExpandedChemistry.cs   Семейства соединений и модели реакций
Domain/ChemicalFormula.cs     Разбор формул и точная балансировка
Domain/PeriodicTable.cs       Все 118 химических элементов
Domain/ReactionEngine.cs      Поиск реакций без зависимости от порядка
wwwroot/                     HTML, CSS и JavaScript интерфейса
Properties/launchSettings.json  Адрес для dotnet run
tests/                       Проверки каталога и цепочек реакций
.vscode/                     Настройки запуска и сборки в VS Code
```

API: `GET /api/catalog` возвращает вещества, все варианты и статистику; `POST /api/react` принимает JSON `{"firstId":"fe","secondId":"o2","variantId":null}`; `GET /api/health` проверяет сервер. Неизвестный идентификатор вещества или вариант от другой пары возвращает HTTP 400; отсутствие реакции — HTTP 200 с `matched: false`. Для выбора конкретного варианта передайте его `id` из каталога; без `variantId` используется первый.

Для добавления конкретной реакции внесите вещества и уравнение в `Domain/ChemistryCatalog.cs`. Семейства расширяются в `Domain/ExpandedChemistry.cs`; коэффициенты вычисляются точной рациональной арифметикой. Затем запустите проверки. Изомеры не объединяются по одной молекулярной формуле. Секреты и серверное хранилище не требуются.

## Публикация локальной сборки

```sh
dotnet publish --configuration Release --output artifacts/publish
```

Архив исходников открывается и запускается так же, как Git checkout. Сгенерированные `bin`, `obj` и SDK в архив включать не нужно.
