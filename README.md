# Реактив — виртуальная химическая лаборатория

Приложение на **ASP.NET Core / .NET 10** с русским интерфейсом. Выбирайте два вещества, наблюдайте уравнение реакции и используйте полученные соединения в следующих экспериментах. Внешние библиотеки, база данных, ключи API и подключение к интернету для работы приложения не нужны.

В каталоге **64 вещества и 70 реакций**. Все уравнения сбалансированы; все вещества можно получить из исходного набора.

## Запуск в VS Code

1. Установите **.NET 10 SDK**: https://dotnet.microsoft.com/download/dotnet/10.0. Нужен именно SDK, а не только Runtime.
2. Откройте папку проекта в VS Code: в ней должен находиться `Grenade.csproj`.
3. Откройте встроенный терминал и выполните:

   ```sh
   dotnet run
   ```

4. Откройте **http://localhost:5186** в браузере. Если браузер не открылся автоматически, скопируйте адрес из терминала.

Для остановки нажмите `Ctrl+C`. Windows, Linux и macOS поддерживаются. Для отладки через `F5` установите расширение Microsoft **C#** (`ms-dotnettools.csharp`); настройки сборки и запуска уже включены в `.vscode`.

Если порт занят, используйте другой:

```sh
dotnet run --no-launch-profile --urls http://localhost:5187
```

## Как пользоваться

- **Первый столбец — элементы:** железо, медь, магний, сера и другие простые вещества.
- **Второй — реагенты:** кислород, водород, вода, кислоты, щёлочь и соли.
- **Третий — открытия:** все полученные продукты, включая несколько продуктов одной реакции.
- Нажмите на две карточки **из любых столбцов, включая один и тот же**, затем нажмите **«Смешать вещества»**. Повторное нажатие снимает выбор. Чтобы заменить выбранное вещество, сначала нажмите на его ячейку на столе.
- Можно **перетащить одну карточку на другую** для немедленного смешивания или перетащить её в ячейку стола. На телефоне пользуйтесь нажатиями.
- Полученные вещества доступны для следующих реакций без ограничения количества: это учебная модель, расход веществ не моделируется.
- Поиск понимает русские названия и формулы, в том числе `O2` и `O₂`. Рядом находится фильтр типов веществ.
- В **справочнике реакций** есть условия и готовые пары. Кнопка с часами открывает журнал последних 50 успешных реакций.
- Открытия и история автоматически сохраняются в `localStorage` текущего браузера для адреса приложения. Их можно удалить кнопкой **«Сбросить прогресс»** с подтверждением. Если сохранение браузером запрещено, приложение продолжает работать в текущей вкладке.

### Пример цепочки

1. **Железо + кислород → оксид железа(III)**: `4Fe + 3O2 → 2Fe2O3`.
2. Выберите **оксид железа(III)** из третьего столбца и **железо** из первого: `Fe2O3 + Fe → 3FeO`.
3. Смешайте полученный **оксид железа(II)** с **соляной кислотой**: `FeO + 2HCl → FeCl2 + H2O`.

Модель использует конечный справочник, а не пытается предсказать произвольную химическую реакцию. Для отсутствующей пары она прямо сообщает об этом. Условия указаны для каждого уравнения: например, продукт окисления железа зависит от температуры и доступности кислорода. Приложение не моделирует количества, скорость, равновесие и все возможные побочные продукты. В случае хлороводорода предполагается его последующее растворение в воде.

## Проверки

```sh
dotnet build --configuration Release
dotnet run --project tests/Grenade.Checks.csproj --configuration Release
```

Проверки запускаются без стороннего тестового фреймворка и завершаются ненулевым кодом при ошибке. Они проверяют цепочку с оксидами железа, независимость от порядка реагентов, смешивание внутри и между столбцами, существование продуктов, **баланс атомов каждого уравнения**, соответствие уравнений каталогу и достижимость всех веществ.

## Структура

```text
Program.cs                   HTTP-сервер и API
Domain/ChemistryCatalog.cs    Вещества, реакции, условия и пояснения
Domain/ReactionEngine.cs      Поиск реакций без зависимости от порядка
wwwroot/                     HTML, CSS и JavaScript интерфейса
Properties/launchSettings.json  Адрес для dotnet run
tests/                       Проверки каталога и цепочек реакций
.vscode/                     Настройки запуска и сборки в VS Code
```

API: `GET /api/catalog`, `POST /api/react` с JSON `{"firstId":"fe","secondId":"o2"}`, `GET /api/health`. Неизвестный идентификатор возвращает HTTP 400; отсутствие реакции — HTTP 200 с `matched: false`.

Для добавления реакции внесите вещества и сбалансированное уравнение в `Domain/ChemistryCatalog.cs`, затем запустите проверки. Секреты и серверное хранилище не требуются.

## Публикация локальной сборки

```sh
dotnet publish --configuration Release --output artifacts/publish
```

Архив исходников открывается и запускается так же, как Git checkout. Сгенерированные `bin`, `obj` и SDK в архив включать не нужно.
